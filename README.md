# Проект «Посмотри в окно»

> Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» от Яндекс Практикума по стилизации готового веб-приложения.

### Задача проекта:
- Оформить интерфейс по макету, дополнив CSS для готовой HTML-разметки.
- Сохранить существующую функциональность поиска, загрузки и переключения видео.
- Настроить состояния интерактивных элементов и оформление динамически добавляемого контента.

## Описание проекта

**«Посмотри в окно»** — веб-приложение для знакомства с городами через видео, снятые из окон. Пользователь может найти ролики по городу и времени суток, переключаться между ними и загружать дополнительные результаты.

HTML-разметка и JavaScript-логика предоставлены в заготовке. Моя задача — CSS-оформление приложения.

## Реализовала:
- Настроила композицию страницы на Flexbox: расположение видеоплеера, формы поиска, заголовка и списка карточек.
- Подогнала размеры блоков, отступы и типографику под макет.
- Оформила видео и превью карточек с учётом размеров контейнеров.
- Настроила ограниченную по высоте область результатов с вертикальной прокруткой.
- Стилизовала поле поиска и создала собственное оформление чекбоксов с помощью псевдоэлементов.
- Добавила состояния наведения, нажатия и клавиатурного фокуса для кнопок и карточек.
- Выделила выбранную карточку через класс, который устанавливает готовый скрипт.
- Настроила позиционирование готовых прелоадеров внутри соответствующих блоков.
- Вынесла общие стили кнопок в единый класс, сохранив различия в их размерах и расположении.

## Результат:
- Научилась работать с готовой разметкой и логикой приложения, изменяя его оформление без вмешательства в функциональность.
- Закрепила навыки построения композиции на Flexbox, управления размерами элементов и переполнением контента.
- Освоила оформление полей ввода и чекбоксов, работу с псевдоклассами и псевдоэлементами.
- Научилась различать состояния выбранного элемента, нажатия, наведения и клавиатурного фокуса.
- Разобралась, как CSS применяется к элементам, которые JavaScript создаёт из HTML-шаблонов.
