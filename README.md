# Посмотри в окно

**Посмотри в окно** — веб-приложение, которое позволяет увидеть разные города через короткие видео, снятые из окон.

## Технологический стек:

## Основной функционал:
- Поиск видео по названию города.
- Фильтрация по времени суток: утро, день и ночь.
- Просмотр выбранного ролика во встроенном видеоплеере.
- Переключение между видео через карточки с превью и описанием.
- Загрузка дополнительных результатов по кнопке «Показать ещё».
- Индикация загрузки и сообщения об отсутствии результатов или ошибке получения данных.

## Реализация:
- Страница построена на HTML и CSS, интерактивность реализована на JavaScript.
- Данные загружаются с внешнего API через `fetch`, параметры поиска передаются в запросе.
- Карточки, индикаторы загрузки и сообщения об ошибках создаются из HTML-шаблонов `template`.
- Для воспроизведения используется элемент `video` со стандартными средствами управления.
- Результаты загружаются порциями по пять карточек.
- Расположение блоков организовано через Flexbox, вёрстка рассчитана на десктоп.
- Чекбоксы оформлены с помощью псевдоэлементов, для интерактивных элементов предусмотрены состояния наведения и фокуса.
- Шрифты Oswald и Fira Sans Condensed подключены локально.
